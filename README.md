# Cool Website — Liquid Glass Studio Landing

Dark cinematic web design agency landing page built with:

- **React** + **Vite** + **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- Liquid glass morphism UI

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build for production

```bash
npm run build
```

Output goes to `dist/`. For GitHub Pages the base path is already set to `/cool-website/`.

## Structure

- `src/App.tsx` — Hero + Capabilities sections
- `src/components/FadingVideo.tsx` — Video with fade in/out
- `src/components/BlurText.tsx` — Staggered blur-in text
- `src/components/Icons.tsx` — Custom SVG icons
- `src/index.css` — Liquid glass styles + Tailwind
